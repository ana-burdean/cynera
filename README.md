# Cynera

## Endpoint Detection and Response System for Behavioral Threat Detection

Cynera is a lightweight Endpoint Detection and Response (EDR) system
designed to detect suspicious endpoint behavior, analyze security
telemetry, generate risk-based incidents, and perform automated
response actions.

## Components

- Cynera Agent
- Cynera Backend
- Cynera Frontend
- Cynera ML Service
- Cynera Infrastructure

## Technology Stack

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- Python
- React
- TypeScript
- Docker
- OpenAPI
- Postman

## Main Security Scenarios

- Ransomware behavior detection and prevention
- Suspicious process behavior
- Persistence detection
- Malicious network behavior
- Behavioral threat detection
- Automated incident response
